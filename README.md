# CoverON — сайт группы

Статический одностраничный сайт. Без сборки и зависимостей.

- `index.html` — вся страница: стили, разметка, скрипт.
- `logos/` — SVG-логотипы групп для бегущих строк (Wikimedia Commons, public domain как текстовые логотипы).

Шрифты подгружаются с Google Fonts (Oswald, IBM Plex Sans, IBM Plex Mono, Metal Mania, New Rocker, Russo One, Ruslan Display).

## Запуск

Открыть `index.html` в браузере или поднять любой статический сервер:

    python3 -m http.server 8000

## Что ещё заглушки

- Афиша (даты и площадки), состав и фото, ссылки на видео и соцсети, почта и телефон.
- Форма букинга только показывает подтверждение, никуда не отправляет. Для реальной отправки нужен бэкенд или сервис форм.
